# README

This hold code for my replacement for Blynk like application. 
It use for my other project in my FYP. This is free to use and modify as everyone like.

It interact using get and post request so it should be accessible to any device that can use internet.

this project use JSON file for saving design.

dashboardhoster.py for hosting the dashboard
dashboardcreator.py for creating the dashboard design file

## Deployment for Render
I use render as bases for this hosting so here some guide to deploy it to flask. 
But should still work as local system hosting. 
Follow the guide at https://render.com/docs/deploy-flask.

# Setting Default Design 

Put the design file into folder defaultDashboardGeneration within the same file as hoster.
